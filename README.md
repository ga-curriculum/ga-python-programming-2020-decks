# Python programming slide decks

The slide decks for GA's Python programming course, published at https://ga-curriculum.github.io/ga-python-programming-2020-decks/.

This repo is a copy of `modules/python-programming/deployment/` in [ga-curriculum-custom/ga-python-programming-2020](https://github.com/ga-curriculum-custom/ga-python-programming-2020), taken from commit `17e9cae`. That repo stays the source: make deck changes there, then copy the changed files here. A push to `main` republishes the site.

To present a deck with speaker notes, open it with `?instructor=1` on the end of its address and press `s`. Give students the address without it.
